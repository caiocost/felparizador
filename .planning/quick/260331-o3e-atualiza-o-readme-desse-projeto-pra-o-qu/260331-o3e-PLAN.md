**Title and tagline:**
- "ffmpeg10mb" with a one-liner: compress any video to under 10 MB for Discord uploads.

**What it does (brief):**
- Takes any video input, outputs an MP4 guaranteed under 9.8 MiB (Discord's upload limit for free users).
- Uses two-pass H.264 + AAC encoding for videos >= 30s, single-pass CRF for shorter clips.
- Automatically calculates optimal video bitrate given duration and audio settings.
- Bundled ffmpeg via ffmpeg-static (no system ffmpeg install required).

**Prerequisites:**
- Node.js >= 22
- npm install (ffmpeg-static provides the binary)

**Installation:**
```
git clone ...
cd ffmpeg10mb
npm install
```

**CLI Usage:**
- Basic: `npm run cli -- video.mp4`
- With output path: `npm run cli -- -o out.mp4 video.mp4`
- Strip audio: `npm run cli -- --no-audio video.mp4`
- Custom size target: `npm run cli -- --target 8 video.mp4` (for 8 MiB ceiling)
- Dry run: `npm run cli -- --dry-run video.mp4`
- Show all the flags from the CLI help text (--help, -o/--output, --no-audio, --target, --audio-bitrate, --dry-run)

**Electron GUI:**
- `npm run gui` launches a drag-and-drop desktop app
- Mention it builds TypeScript first then launches Electron

**Programmatic API:**
- Show a brief example importing from the package:
```ts
import { probeVideo, encodeVideo, verifyOutput } from "ffmpeg10mb";
```
- List the key exports: probeVideo, encodeVideo, verifyOutput, calculateVideoBitrate
- Note the EncodeOptions interface for customization (quiet mode, onProgress callback, custom target bytes)

**Running tests:**
- `npm test` (uses node:test built-in runner, no external framework)

**How it works (brief technical section):**
- Probes input with ffprobe for duration, resolution, audio presence
- Calculates video bitrate: (targetBytes * 8 - audioBits) / duration
- Encodes: two-pass H.264 for >= 30s, CRF single-pass with maxrate cap for < 30s
- Verifies output is under ceiling (9.8 MiB default)
- Effective target is 9.6 MiB to leave headroom for container overhead
