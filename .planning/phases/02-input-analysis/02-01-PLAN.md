    **`resolveFfprobePath(cliFlag?: string): Promise<string>`** (change from sync to async)
    - If `cliFlag` provided, return it
    - Try `await execa('ffprobe', ['-version'])` — if succeeds, return `'ffprobe'` (it's on PATH)
    - On ENOENT error (check `(err as NodeJS.ErrnoException).code === 'ENOENT'`), throw `new FfmpegNotFoundError(buildInstallMessage())`
    - On other errors, rethrow

    **IMPORTANT:** `resolveFfmpegPath()` (for ffmpeg binary) must REMAIN as-is — it is used by Phase 3 for encoding. Add `resolveFfprobePath()` as a NEW separate function. Do NOT remove or rename `resolveFfmpegPath()`.

    **`validateInputFile(inputPath: string): Promise<void>`** (not exported — internal helper)
    - `await access(inputPath, constants.R_OK)`
    - On error: `throw new InputValidationError(\`Input file not found or not readable: ${inputPath}\`)`

    **`probeVideo(inputPath: string): Promise<ProbeResult>`** (replace stub)
    - Call `const ffprobePath = await resolveFfprobePath()` — this handles INPUT-01
    - Call `await validateInputFile(inputPath)` — this handles INPUT-02
    - Spawn ffprobe: `const { stdout } = await execa(ffprobePath, ['-v', 'quiet', '-print_format', 'json', '-show_streams', '-show_format', inputPath])`
    - Parse JSON: `const data = JSON.parse(stdout)`
    - Extract duration with N/A fallback: check `data.format?.duration` first (string, parseFloat), if absent/NaN/"N/A" fall back to `data.streams.find(s => s.codec_type === 'video')?.duration`; if still NaN/absent, throw `new InputValidationError('Could not determine video duration')`
    - Find video stream: `data.streams.find(s => s.codec_type === 'video')`
    - Find audio stream: `data.streams.find(s => s.codec_type === 'audio')`
    - Build and return ProbeResult:
      ```typescript
      {
        durationSeconds,
        hasAudio: audioStream !== undefined,
        audioBitrateKbps: audioStream ? Math.round(parseInt(audioStream.bit_rate ?? '128000', 10) / 1000) : 0,
        widthPx: videoStream?.width ?? 0,
        heightPx: videoStream?.height ?? 0,
        fileSizeBytes: parseInt(data.format?.size ?? '0', 10),
      }
      ```

    **CRITICAL PARSING RULES:**
    - `format.duration` is a STRING — use `parseFloat()`, NOT direct number access
    - Audio `bit_rate` is bits/second — divide by 1000 for kbps
    - `format.size` is a STRING of bytes — use `parseInt(str, 10)`
    - Always use radix 10 with `parseInt` to avoid octal issues
